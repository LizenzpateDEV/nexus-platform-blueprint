# ADR-0001: PostgreSQL als primäre Datenbank

## Status

Accepted

## Kontext

NexusERP AI benötigt eine relationale Datenbank mit hoher Stabilität, ACID-Konformität und exzellenter Unterstützung für Mandantenfähigkeit, Reporting und Integrationen.

## Entscheidung

Die Plattform verwendet PostgreSQL als primäre relationale Datenbank.

Für die erste Version wird Supabase als Managed PostgreSQL-Plattform genutzt.

Die Architektur bleibt so gestaltet, dass später auch selbst gehostete PostgreSQL-Instanzen unterstützt werden können.

## Begründung

- Open Source
- Bewährt im Enterprise-Bereich
- ACID-konform
- JSONB-Unterstützung
- Gute Performance
- Starke Community
- Skalierbar
- Kein Vendor-Lock-in

## Konsequenzen

Alle Module verwenden dieselbe Datenbankplattform.

Spezifische Geschäftslogik wird nicht in der Datenbank implementiert, sondern in Services.

## Alternativen

- MySQL
- MariaDB
- Microsoft SQL Server

Diese wurden aufgrund geringerer Flexibilität oder höherer Betriebskosten verworfen.
